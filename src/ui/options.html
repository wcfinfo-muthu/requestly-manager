📋 Rule Format Reference

JSON format for all rule types. Copy and modify to create custom rules.

[
  {
    "name": "Redirect staging to prod",
    "type": "redirect",
    "sourcePattern": "*://staging.myapp.com/*",
    "destination": "https://prod.myapp.com/",
    "enabled": true,
    "pinned": true
  },
  {
    "name": "Block ads",
    "type": "block",
    "sourcePattern": "*://ads.example.com/*",
    "enabled": true,
    "pinned": false
  },
  {
    "name": "Replace hostname",
    "type": "replace",
    "sourcePattern": "*://dev.example.com/*",
    "findText": "dev.example.com",
    "replaceText": "prod.example.com",
    "enabled": true,
    "pinned": false
  },
  {
    "name": "Add auth header",
    "type": "headers",
    "sourcePattern": "*://api.example.com/*",
    "headersAdd": { "Authorization": "Bearer TOKEN" },
    "headersRemove": ["Cookie"],
    "headersModify": { "User-Agent": "Custom" },
    "enabled": true,
    "pinned": false
  },
  {
    "name": "Mock API response",
    "type": "response",
    "sourcePattern": "*://api.example.com/data",
    "responseStatus": 200,
    "responseBody": { "message": "mocked response" },
    "enabled": true,
    "pinned": false
  }
]

💡 Tips & Safety

  • Regular backups: Export your rules weekly to prevent data loss
  • JSON validation: Ensure JSON is valid before importing (use online validator)
  • Merge behavior: Import merges with existing rules, doesn't replace them
  • Sensitive data: Don't export if rules contain passwords or tokens
  • File naming: Auto-generated filenames include date for easy organization
